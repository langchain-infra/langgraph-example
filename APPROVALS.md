# Approval policy

Open SWE may approve a pull request only when every changed file is a Markdown
documentation file (`*.md`) and the change is limited to prose: wording, typos,
formatting, or links.

Always require human review when a pull request:

- changes any non-Markdown file, including code, configuration, or CI;
- changes this `APPROVALS.md` file;
- has any unresolved review finding.
